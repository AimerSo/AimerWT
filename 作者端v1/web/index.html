作者端说明与使用指南

这是面向 AimerWT 合作创作者的作者端，用于维护语音包与炮镜的发布信息。遇到问题或有建议都可以直接反馈，后续界面与流程仍会持续完善。

1. 语音包管理

在“语音包库”中可创建、重命名、删除语音包目录，并快速打开语音包库路径。

2. 信息编辑

在“语音包信息”中填写名称、作者、版本、标签、链接、作者留言与版本说明等内容。

3. 试听与关联

主语音包与关联语音包都支持试听音频与封面图，发布前请确认链接可访问、素材可播放。

4. 导入与导出

支持导入 .bank/.zip，也可将当前语音包导出为标准化命名的 .bank 文件。

5. 数据存储

语音包元数据写入 info.json，预览媒体文件写入语音包目录中的 _preview_assets。

6. 炮镜作者项目

在“炮镜信息”中新建项目，或导入单个 BLK、炮镜文件夹与 ZIP。作者项目使用独立工作副本；需要时可明确选择写回原 BLK 或另存为。

7. 文件映射与分组

逐个确认真实 .blk 的 ZIP 输出路径、弹种与推荐载具；多炮镜可建立展示分组，同一文件首版只归属一个主分组。

8. 检查与标准 ZIP

炮镜项目必须先保存并通过最新兼容性检查才能导出。单炮镜同样导出 ZIP，类型由真实 BLK 数量自动判断。
